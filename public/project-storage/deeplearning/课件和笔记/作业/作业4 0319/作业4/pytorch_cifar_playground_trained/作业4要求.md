## 三、实验任务

### 任务1：首次训练体验（必做）

1. **运行基础训练**（约5-10个epoch即可，观察流程）：
   
   ```bash
   python main.py --epochs 10 --seed 42
   ```

2. **观察终端输出**：
   
   - 训练过程中每个 batch 的损失和准确率
   - 每个 epoch 结束后的测试准确率
   - 学习率的变化

3. **记录观察结果**：
   
   - 训练集和测试集的准确率变化趋势
   - 是否有"过拟合"迹象？（训练准确率远高于测试准确率）

---

### 任务2：TensorBoard 监控（必做）

1. **启动 TensorBoard**（在另一个终端窗口）：
   
   ```bash
   tensorboard --logdir=runs --load_fast=false
   ```

2. **在浏览器中打开** `http://localhost:6006/`

3. **查看并记录以下内容**：
   
   **SCALARS 标签页**：
   
   - 训练损失（Loss/train）和测试损失（Loss/test）的曲线
   - 训练准确率（Accuracy/train）和测试准确率（Accuracy/test）的曲线
   - 学习率（Learning Rate）的变化曲线
   - 每个类别的准确率（Class_Accuracy/*）
   
   **TEXT 标签页**：
   
   - 查看超参数设置
   - 查看最佳模型保存信息

4. **思考问题**（在实验报告中回答）：
   
   - 为什么训练损失通常低于测试损失？
   - 哪个类别的准确率最低？可能是什么原因？

---

### 任务3：对比实验（必做）

进行**两组不同的训练配置对比**，记录并分析结果：

**实验 A：调整学习率**

```bash
python main.py --lr 0.01 --epochs 20 --seed 42
```

**实验 B：调整 Batch Size**

```bash
python main.py --batch_size 64 --epochs 20 --seed 42
```

**对比分析要求**：

1. 在 TensorBoard 中同时显示两组实验的曲线（勾选多个 Runs）
2. 对比以下内容：
   - 收敛速度（哪个实验更快达到较高准确率？）
   - 最终准确率
   - 训练稳定性（曲线是否平滑？）
3. 解释观察到的差异原因

### 任务4：模型保存与恢复训练（必做）

1. **先进行一段训练**（如10个epoch）：
   
   ```bash
   python main.py --epochs 10 --seed 42
   ```
   
   观察终端输出的最佳准确率，检查 `checkpoint/ckpt_best.pth` 是否生成

2. **恢复训练**（从保存的 checkpoint 继续训练10个epoch）：
   
   ```bash
   python main.py --resume --epochs 10 --lr 0.01
   ```
   
   观察终端输出：
   
   - 是否加载了之前的最佳准确率？
   - 训练是否从第10个epoch继续？

3. **思考问题**（在实验报告中回答）：
   
   - 为什么要同时保存 `net`, `optimizer`, `scheduler` 的状态？
   - 如果只保存模型权重，恢复训练会有什么问题？
   - checkpoint 文件中的内容有哪些？（可用 `torch.load()` 查看）

## 七、提示与建议

1. **训练时间**：每个 epoch 在 mps上约需 2-4分钟，建议初期先用较少的 epoch（如10）熟悉流程

2. **磁盘空间**：CIFAR-10 数据集约 170MB，训练过程中产生的日志和模型文件会占用额外空间

3. **多次实验**：每次实验都会创建新的 runs 子文件夹，可以用 TensorBoard 对比不同实验的结果

4. **遇到问题**：
   
   - 查看 `logs/` 目录下的日志文件
   - 检查 `checkpoint/` 目录是否正确生成
   - 确保 conda 环境已正确激活
